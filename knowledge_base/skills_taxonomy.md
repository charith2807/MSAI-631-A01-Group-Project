# Skills taxonomy

Format: `- Canonical | alias, alias | related skills | learning suggestion`
Aliases are matched literally and case-insensitively. Related skills mark adjacent experience (used for "transferable" classification).

## Programming
- Python | python3, py | R | Complete a small data-cleaning script project and publish it with tests.
- Java | java se, jdk | Python, C# | Build a small REST service with Spring Boot and unit tests.
- JavaScript | js, ecmascript | TypeScript, Node.js | Build an interactive page without a framework, then port it to React.
- TypeScript | ts | JavaScript | Convert a small JavaScript project to TypeScript with strict mode on.
- C++ | cpp | C#, Java | Implement common data structures in C++ and benchmark them.
- C# | csharp, c-sharp | Java, C++ | Build a small .NET console or web API project.
- Go | golang | | Write a concurrent web crawler or small HTTP service in Go.
- SQL | structured query language | PostgreSQL, MySQL | Practice joins, aggregates, and window functions on a public dataset.
- Bash | shell scripting, shell | Linux | Automate a repetitive task with a documented shell script.
